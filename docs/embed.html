Community embedding

Put live transit context where your community already looks.

Schools, nonprofits, neighborhood organizations, and local publications can add MBTA Tracker without taking on its application code. Use an iframe for the most isolated, reliable integration.

Embed example

<iframe src="https://mbta.ai-aarti.com/embed?embed=1&ws=wss://YOUR_FEED_HOST/ws" title="MBTA Live Tracker" loading="lazy" style="width:100%;height:720px;border:0"></iframe>

Before publishing

  • Use wss:// on HTTPS pages.
  • Keep an explicit iframe height so controls remain usable.
  • Use a descriptive title for screen-reader users.
  • Link nearby text to the full MBTA Tracker experience.
  • For major disruptions, link readers to official MBTA information as well.

For script-tag, programmatic, query-parameter, and accessibility details, read the complete widget embed guide.
