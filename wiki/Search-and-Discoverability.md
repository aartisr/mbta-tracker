# Search and discoverability

The primary public destination is [https://mbta.ai-aarti.com/](https://mbta.ai-aarti.com/). Repository, wiki, and GitHub Pages content should link to that URL consistently.

## Editorial standard

Write pages that answer one real rider or integrator question, with:

- a precise title and short first-paragraph answer;
- factual, sourceable claims;
- clear links to the relevant canonical MBTA Tracker page;
- an update date when information can change;
- no invented performance claims, testimonials, or affiliate-style link schemes.

## Publishing checklist

- Link to the production URL, never an alternate preview URL.
- Keep canonical tags on GitHub Pages pointed at `https://mbta.ai-aarti.com/`.
- Keep the production sitemap limited to production canonical URLs.
- Validate structured data against visible on-page content.
- Submit the production sitemap—not the GitHub Pages sitemap—to Search Console and Bing Webmaster Tools.

External backlinks should be earned by useful community resources, integrations, and legitimate editorial coverage. Creating deceptive directories, automated links, or paid link schemes risks search-engine penalties and damages reader trust.
